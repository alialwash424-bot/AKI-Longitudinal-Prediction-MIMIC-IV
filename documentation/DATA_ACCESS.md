# Data Access

MIMIC-IV patient-level data are not distributed with this repository.

Researchers seeking to reproduce the study must independently obtain
authorized access to MIMIC-IV through PhysioNet and satisfy the applicable
credentialing and data-use requirements.

The repository excludes:

- original MIMIC-IV patient-level tables;
- patient-level derived datasets;
- patient identifiers;
- patient-level predictions;
- patient-level split manifests.

References in source code to MIMIC-IV table names or schema column names are
included solely to describe the reproducible analysis workflow.
